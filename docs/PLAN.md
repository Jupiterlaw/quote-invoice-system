# 一頁紙計劃 — 報價及發票系統

**結論：** 套系統只做三件事 — 出報價快、報價一鍵變發票、邊張單未收錢一眼睇晒。

## 每日四步

1. 入客資料同工程項目
2. 系統自動計總額
3. 客確認後一鍵轉發票（編號跟 INV-2026-059 打後自動接）
4. 標記已收／未收，過期自動提

## 系統記低咩

客戶公司名、聯絡電話、地址、工程項目＋金額、日期、狀態。

發票版面跟已定嘅簡潔版：只放公司名、編號、日期、客戶名＋電話、地址一行、項目＋金額＋總額，唔加銀行資料／條款／簽名欄。

## Astryx 幫到邊半

- 幫到「畫面」嗰半：填資料嘅格、清單表格、搜尋、按鈕
- 幫唔到「背後」嗰半：自動計數、存資料、出 PDF、編號 — 嗰半要另外整

## 兩個做法（已揀 B）

- **A 簡單穩陣版：** 成熟穩定嘅現成零件，起得快、少保養
- **B Astryx 版（2026-11-27 拍板揀呢個）：** 畫面最整齊、AI 幫手寫嗰陣最準；但佢仲係試驗版（0.7.x），更新密、要跟住保養
